# 📦 מערכת ניהול הזמנות שרשרת אספקה

כלי אוטומציה מתקדם ב־Python לניהול וניתוח תהליכי הזמנות בשרשרת אספקה.
המערכת כוללת אינטגרציה מלאה דו-כיוונית עם REST API (דמי), תומכת בקבצי Excel, ויוצרת דוחות, לוגים והתראות בצורה אוטומטית.

## 📌 תכונות עיקריות
- 🔁 אינטגרציה עם API (יצירה, עדכון, מחיקה, שליפה)
- 📊 ניתוח ועדכון אוטומטי של קבצי Excel
- 📁 גיבויים יומיים אוטומטיים
- 📈 הפקת דוחות Excel, PDF ולוחות בקרה
- 📬 שליחת התראות במייל במקרה שגיאה
- 🧪 מצב סימולציה (ללא שליחה)
- 🧩 רישום פעילות (Log) ודוחות מעקב
